# C7 Script — theme assets

Game art and logos used by the C7 Script store theme (c7-script.com).
Served through jsDelivr, pinned by tag:

`https://cdn.jsdelivr.net/gh/virusmohammed58-pixel/c7-assets@1.0.0/art/<game>.webp`

- `art/` character art, up to 900px (hero, product page)
- `art-s/` same art, up to 440px (cards, game row)
- `logo/`, `logo-s/` white game logos
